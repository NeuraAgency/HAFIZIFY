  HAFIZIFY — QURAN ASR: LORA ADAPTATION & ACCURACY IMPROVEMENT GUIDE
================================================================================

1. CURRENT LOCAL MODEL ARCHITECTURE
--------------------------------------------------------------------------------
- Base Model  : tarteel-ai/whisper-base-ar-quran (Whisper base fine-tuned on Quranic Arabic)
- Adapter     : whisper-base-quran-lora (Custom LoRA adapter weights)
- CT2 Output  : whisper-base-quran-lora-ct2 (Quantized int8_float32 CTranslate2 model)

2. HOW LORA IS ALREADY INTEGRATED
--------------------------------------------------------------------------------
In convert_model_ct2.py, the LoRA adapter weights are loaded and merged directly
into the base Tarteel AI model using PEFT:

    base_model = AutoModelForSpeechSeq2Seq.from_pretrained("tarteel-ai/whisper-base-ar-quran")
    model = PeftModel.from_pretrained(base_model, "whisper-base-quran-lora")
    merged_model = model.merge_and_unload()

The fused model is then converted to CTranslate2 int8 format. This provides:
  • 100% of your trained LoRA fine-tuning accuracy.
  • 4x faster CPU decoding speed during real-time streaming.


3. HOW TO IMPROVE ACCURACY WITH FURTHER LORA ADAPTATIONS
--------------------------------------------------------------------------------
You DO NOT lose the Tarteel AI base model when adding more adaptations. Extra
training happens directly on top of tarteel-ai/whisper-base-ar-quran.

A. Continue Training Existing LoRA Adapter
------------------------------------------
Load the existing LoRA adapter on top of Tarteel AI and continue training for
more epochs with extra reciter data or background noise:

    from transformers import AutoModelForSpeechSeq2Seq
    from peft import PeftModel

    base_model = AutoModelForSpeechSeq2Seq.from_pretrained("tarteel-ai/whisper-base-ar-quran")
    model = PeftModel.from_pretrained(base_model, "whisper-base-quran-lora", is_trainable=True)
    # Resume fine-tuning for additional epochs

B. Increase LoRA Rank (r) & Target Modules
------------------------------------------
When training a new LoRA adapter layer:
  - Increase LoRA Rank from r=8 / r=16 to r=32 or r=64.
  - Expand target_modules to cover all linear layers:
        target_modules=["q_proj", "k_proj", "v_proj", "out_proj", "fc1", "fc2"]

C. Stacking / Combining Multiple LoRA Adapters
---------------------------------------------
You can combine multiple specialized LoRA adapters (e.g. general Quran ASR + Tajweed rules)
using PEFT:

    from peft import PeftModel

    base_model = AutoModelForSpeechSeq2Seq.from_pretrained("tarteel-ai/whisper-base-ar-quran")
    model = PeftModel.from_pretrained(base_model, "lora-adapter-1")
    model.load_adapter("lora-adapter-2", adapter_name="tajweed")
    model.add_weighted_adapter(
        adapters=["default", "tajweed"],
        weights=[0.7, 0.3],
        adapter_name="combined"
    )
    merged_model = model.merge_and_unload()

D. Convert Fused Model to CTranslate2
-------------------------------------
After merging new LoRA weights, re-run convert_model_ct2.py:

    python convert_model_ct2.py --base tarteel-ai/whisper-base-ar-quran \
                                --adapter whisper-base-quran-lora \
                                --output whisper-base-quran-lora-ct2 \
                                --quantization int8_float32
